# TREX / Max Fit

Мобильное приложение на Expo + React Native с маскотом Максом, тренировочными ветками, прогрессом и магазином аксессуаров.


## Запуск

Требуется Node.js LTS.

```bash
npm install
npx expo start
```

Для Android можно открыть проект в Expo Go, либо собрать APK через EAS:

```bash
npx eas-cli@latest login
npx eas-cli@latest build -p android --profile preview
```

Для iOS:

```bash
npx eas-cli@latest login
npx eas-cli@latest build -p ios --profile production
```

Для iOS-сборки и публикации потребуется настройка подписи Apple. Публикация в магазинах приложений требует отдельных аккаунтов разработчика и прохождения проверки.

## Персонаж Макс: единая система изображений (актуальная версия)

- Добавлены 25 отдельных иллюстраций в `assets/max-stage/max-stage-01.png` … `max-stage-25.png` (каждый PNG — 1024×1024).
- Во вкладках «Макс», «Профиль», а также в компактном аватаре, онбординге и результате тренировки используется один общий компонент `MaxPortrait` / `MaxStage`. Поэтому изображение и телосложение синхронизированы.
- Аксессуары отображаются отдельным SVG-слоем поверх изображения и не встроены в PNG.
- Базовая форма выбирается по ИМТ; каждые 250 XP добавляют одну визуальную ступень, максимум четыре.
- Полная формула и таблица порогов для роста 175 см находятся в `docs/MAX_MASCOT_MAPPING.md`. Для другого роста вес рассчитывается как `ИМТ × рост(м)²`.
- ИМТ применяется только как игровой параметр выбора изображения, а не как медицинская рекомендация.
